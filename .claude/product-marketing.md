# 자이언트짐 (ZIANT GYM) — 제품/마케팅 컨텍스트

마케팅 스킬을 쓰기 전에 이 문서를 먼저 읽고, 아래 정보를 다시 묻지 말 것. 없는 정보만 사용자에게 확인할 것.

## 사업 개요

- **업종**: 맞춤운동센터 (헬스장 + 퍼스널트레이닝(PT) 전문)
- **지점**: ZIANTGYM1, ZIANTGYM2 (2개 지점 운영)
- **연관 사업**:
  - **피트니스경영신문** — 업계 대상 미디어(기사 기획·작성·공유)
  - **킷스텝** — 회원관리 성장 프로그램 서비스 (외부 헬스장 대상 B2B 성격 + 유입용 단기 수익 프로그램)
  - **종합기능운동학협회** — 트레이너 교육 사업

## 타겟 고객

- 지역 상권 내 헬스/PT 수요자 (오프라인 상권 기반, 배달앱처럼 전국 대상 아님)
- 유입 계기: 체형/자세 문제(밸런스체크), 다이어트, 재활·통증 개선, 단순 헬스 습관 형성
- 재등록·소개가 핵심 — 신규 획득보다 **기존 회원 유지·확장이 비용 대비 효율 높음**

## 고객 생애 흐름 (퍼널)

```
유입 → 예약 → 상담 → 등록(회원권/PT) → 재등록 → 소개
```

- 등록 후 갈림길은 두 갈래: **재등록** 또는 **소개**로 이어져야 함 (이 두 개가 매출의 핵심 반복 엔진)
- 상담 → 등록 전환율이 최근 데이터 기준 약 45% 수준 (개선 여지 있음, `ai-team`의 데이터 에이전트가 매일 진단)

## 유입 채널

- 네이버 플레이스 (영수증 리뷰, 프로그램 리뷰, 예약 수, 저장/구독, 톡톡 문의 — 로컬 검색 최적화가 핵심)
- 네이버 블로그
- 네이버 광고
- 구글
- 인스타그램 (릴스 위주)
- 당근마켓 (지역 커뮤니티)
- 홈페이지 밸런스체크(체형/자세 진단) 랜딩
- 소개 (기존 회원을 통한 유입 — 별도 인센티브 구조 없이 자연발생 중, 구조화 필요)

## 매출 구조

- 신규 등록 (헬스/PT/다이어트 단기 프로그램)
- 재등록 (헬스/PT)
- 마감(만료) 회원 복귀
- 객단가 증가 (업셀 — 척추/밸런스체크 유도, 자인 유도 판매)
- 소개 시스템 (구조화 안 됨 — 개선 대상)

## 지금 자동화되어 있는 것 (`ai-team/` AI 운영팀)

- **제이**(총괄): 매일 데이터 분석 + 우선순위 업무 도출
- **미나**(회원관리): 재등록/이탈위험/미수금 대상 문자 초안 (발송은 반자동, 소개는 스킬만 있고 실제 로직 없음)
- **데이터**(퍼널분석): 병목 구간·채널 효율 진단
- **루나**(마케팅): 블로그 1건 + 인스타그램 1건 콘텐츠 초안 (게시는 사람이 직접)
- 문자 자동 발송(SMS), 소개 프로그램 구조화, 콘텐츠 자동 게시는 아직 미구현

## 브랜드 톤 (기본값 — 필요시 조정)

전문적이면서 친근함. 과장된 광고 문구보다 신뢰감 있는 정보 전달 선호. 지역 밀착형 톤(동네 주민 대상이라는 느낌 유지).
