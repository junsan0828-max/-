# PM Skills (제품 관리 스킬)

출처: [phuryn/pm-skills](https://github.com/phuryn/pm-skills) (MIT License, Pawel Huryn). 68개 스킬 + 슬래시 명령어 42개 (`.claude/commands/`).

마케팅 스킬(`skills/` 나머지)과 다른 목적: **무엇을·왜·어떻게 만들지 결정하고 검증하는** 제품관리 프레임워크. 두 가지로 씀:

1. **ai-team 앱 자체를 만들 때** — `/write-prd`(만들기 전 요구사항 정리), `/ship-check`(다 만든 후 의도-구현 일치 검증), `/sprint`(작업 우선순위), `pm-pre-mortem`(큰 기능 시작 전 실패 시나리오 미리 점검)
2. **자이언트짐 사업 전략 차원** — `pm-swot-analysis`, `pm-competitor-analysis`, `pm-pricing-strategy`, `pm-ideal-customer-profile` 등

이름 충돌 방지를 위해 전부 `pm-` 접두사를 붙여 저장함 (예: 마케팅 스킬의 `marketing-ideas`와 구분하기 위해 `pm-marketing-ideas`).
