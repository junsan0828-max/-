# 블로그 에디터 작성 — 프롬프트 & 다른 PC 세팅 (2026-10-13)

네이버 블로그 에디터에 논문 리뷰 초안을 채우는 작업을 다른 PC에서도 똑같이 하기 위한 문서다.
글 내용 규칙은 `docs/luna-paper-blog-prompt.md`, 이 문서는 **에디터 입력 방식 + 새 PC 세팅**이다.

---

## 1. 새 PC 세팅 (한 번만)

1. **코드 받기**: 리포를 클론하고 `claude/ai-employee-creation-70nexg` 브랜치(또는 머지된 브랜치)를 체크아웃 → `ai-team` 폴더에서 `npm install`.
2. **Claude Code 로그인**: `claude auth status` 가 `loggedIn: true` 여야 한다 (글쓰기는 구독으로 하므로 API 크레딧이 필요 없다).
3. **크롬 설치**: `C:\Program Files\Google\Chrome\Application\chrome.exe` (다른 경로면 `.env`에 `CHROME_PATH=`).
4. **전용 크롬 창**(로그인 유지용 별도 프로필)을 연다 — 아래 `open-blog-editor.bat` 를 바탕화면에 만들고 실행:
   ```bat
   @echo off
   start "" "C:\Program Files\Google\Chrome\Application\chrome.exe" --remote-debugging-port=9222 --user-data-dir="%USERPROFILE%\chrome-ai-profile" https://blog.naver.com/
   ```
   이 창에서 **네이버 로그인은 사람이 직접** 한다 (비밀번호는 AI가 다루지 않는다). 올릴 블로그 계정으로 로그인했는지 확인.
5. **폴더**: 기본은 바탕화면(OneDrive 포함) 아래 `블로그 초안/`. 다른 위치면 `.env`에 `BLOG_DRAFT_DIR=`.
   - `블로그 초안/사진/` : 모자이크가 끝난 승인 사진 + `library.json`(장면 설명) — **이 PC로 복사해 와야 한다** (리포에 없음)
   - `블로그 초안/사진/banner_ziant_blue.png` : 상단 배너
   - `블로그 초안/사진_원본/`, `사진_모자이크확인/` : 자동 생성
6. **얼굴 자동 모자이크(선택)**: `npm run setup-face-mosaic` (파이썬 3 필요, `tools/.venv` 생성). 모델 파일은 리포의 `tools/models/` 에 있다.
7. **설명 카드 이미지**: `ffmpeg` 가 PATH 에 있어야 한다 (카드 3장을 만든다).
8. **시험**: `npm run blog-paper -- --topic "요통 코어 운동"` → 후보가 나오면 정상.

`.env` 에서 바꿀 수 있는 것: `BLOG_DRAFT_DIR`, `CHROME_PATH`, `BLOG_CHROME_PROFILE`, `BLOG_BANNER_URL`(배너 링크), `BLOG_BODY_FONT_SIZE`(기본 16, 끄려면 0), `AI_TEAM_LLM`(기본 claude-code).

## 2. Claude Code에 붙여넣는 "에디터 작성" 프롬프트

> 너는 자이언트짐 마케팅 AI 루나다. 아래 규칙으로 네이버 블로그 에디터에 논문 리뷰 초안을 채운다.
>
> **절대 규칙**
> - 발행·예약·저장 버튼은 절대 누르지 않는다. 채우는 데까지만 하고 최종 확인·발행은 대표가 한다.
> - 로그인은 대표가 직접 한다. 로그인 화면·보안확인(캡차)이 보이면 즉시 멈추고 알린다. 비밀번호를 묻거나 입력하지 않는다.
> - 에디터에 이미 내용이 있으면 덮어쓰지 않고 멈춘다. 항상 새 글쓰기 탭에서 시작하고, 작성 중이던 다른 탭은 건드리지 않는다.
> - 글에 쓰는 사진은 모자이크가 끝나 `library.json`에 등록된 사진만. 직전 글과 겹치지 않게 가장 오래전에 쓴 것부터. 모자이크 여부가 불확실하면 쓰지 않는다.
>
> **순서**
> 1. 초안 확인: `블로그 초안/` 의 가장 최근 `YYYYMMDD_*.md` (없으면 `npm run blog-paper -- --pmcid PMC…` 로 먼저 만든다). 검증 메모(게시 금지)는 에디터에 넣지 않는다.
> 2. `npm run blog-paper -- --fill` 실행 (전용 크롬 창이 떠 있어야 한다. 없으면 자동으로 띄우지만 로그인은 사람이 해야 한다).
> 3. 에디터에 들어가는 것: 제목 → 본문(굵은 글씨 `**…**` 반영, 소제목 앞 이미지) → 태그 → 상단 배너(링크) → 대표 이미지(센터 사진) → 하단 고정 블록(홈페이지·📌소개·예약·오시는 길·톡톡·전화) → 장소.
> 4. 이미지 7장: 센터 사진 3 + AI 제작 카드 3 + 배너 1. AI 제작 이미지는 사진 설명에 "AI 제작 이미지 | …"를 쓰고 AI 표시를 켠다.
> 5. 끝나면 결과(제목, 이미지 수, 굵은 글씨 곳 수, 글자 크기, 주의사항)를 보고하고, 대표가 확인할 것을 알린다: 숫자 원문 대조, 배너 링크, 장소, 계정, "논문 내용은 대표가 확인했습니다" 문구.
> 6. 실패하면 이유를 그대로 알린다. 같은 동작을 반복 재시도하지 말고, 원인(로그인/기존 내용/선택자 변경)을 말하고 멈춘다.

## 3. 에디터 입력에서 배운 것 (코드에 반영됨 — 문제 생기면 여기부터)

| 증상 | 원인 | 처리 |
|---|---|---|
| "에디터에 이미 내용이 있습니다"로 중단 | 빈 에디터의 "글감과 함께…" 안내 문구를 내용으로 오인 | `.se-placeholder` 제외하고 판정 |
| 문장 끝 💪 입력 시 글자가 사라지고 이모지만 남음 | 글자와 이모지를 한 번에 `insertText` | 이모지는 따로 입력 |
| 이미지 올린 뒤 클릭이 안 먹음 (`sidebar intercepts pointer events`) | 이미지 업로드 후 오른쪽 '라이브러리' 패널이 열림 | 이미지 작업 전후에 패널 닫기 |
| 굵게를 켠 줄에서 앞 글자가 중복 입력됨 | 서식 바꿀 때 입력 중이던 글자가 확정되지 않음 | 서식 전환 전에 `End` 키로 확정 |
| 굵게가 안 먹는 것처럼 보임 | 굵은 글자는 `<span><b>…</b></span>` 로 저장됨 (span 의 weight 는 400) | `<b>` 개수로 확인 |
| 로그인 풀림 | 전용 프로필 세션 만료 | 전용 크롬에서 사람이 로그인 후 재시도 |

굵게: 도구 모음 `button.se-bold-toolbar-button` 클릭으로 켜고 끈다. 글자 크기: 본문 전체 선택 후 `.se-font-size-code-toolbar-button` → `.se-toolbar-option-font-size-code-fs16-button`.
네이버 에디터 화면이 바뀌면 선택자가 깨질 수 있다 — 그때는 `src/main/blogEditor.ts` 의 해당 부분만 고친다.

## 4. 점검 체크리스트 (새 PC에서 처음 돌릴 때)

- [ ] `claude auth status` → loggedIn
- [ ] 전용 크롬 창이 떠 있고 올릴 계정으로 네이버 로그인됨
- [ ] `블로그 초안/사진/` 에 승인 사진 3장 이상 + `library.json` + 배너
- [ ] `ffmpeg -version` 동작
- [ ] `npm run blog-paper -- --topic …` 후보 검색 성공
- [ ] 초안 1건 생성 → `--fill` → 에디터에 제목·본문·이미지 7장·하단 블록·장소 확인
- [ ] 발행 버튼은 누르지 않았는지 확인
