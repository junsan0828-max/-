# 처음 세팅 — AI가 센터 정보를 물어보고 만들어 주는 프롬프트

아래 박스 전체를 Claude Code(또는 같은 종류의 AI 코딩 도구)에 붙여넣으면, AI가 센터 정보를 **질문으로 받아서** 설정 파일을 만든다.
센터 이름·주소·전화·링크는 어디에도 미리 박혀 있지 않다. 이 인터뷰가 유일한 입력이다.

---

```
너는 내 블로그 자동화(논문 리뷰 글 초안 + 네이버 블로그 에디터 입력)를 세팅해 주는 도우미다.
먼저 나에게 센터 정보를 물어보고, 답을 받아 설정 파일(config/blog-center.json)을 만든 뒤, 환경 점검까지 한다.

[진행 규칙]
- 질문은 한국어로, 한 번에 최대 5개씩 묶어서 묻는다. 내가 답하지 않은 항목을 추측해서 채우지 않는다. 모르겠다고 하면 비워 두고 나중에 채울 목록에 적는다.
- 아래 항목을 모두 받으면, 받은 내용을 표로 보여 주고 "이대로 만들까요?"를 확인한 뒤에 파일을 만든다.
- 네이버 비밀번호·인증번호는 절대 묻지 않는다. 로그인은 내가 직접 한다.
- 회원 개인정보(이름·연락처·얼굴 사진)는 받지 않는다.

[물어볼 항목]
1. 센터: 이름, 종류(예: 맞춤운동센터/필라테스/PT 스튜디오), 지역(○○시 ○○동), 대표 이름과 호칭(기본 "대표")
2. 검색 키워드: 제목 앞에 붙일 키워드 1개(예: ○○동헬스장), 본문에 자연스럽게 넣을 키워드 3개
3. 센터 진행 방식 5단계: 상담~운동 진행 순서를 5단계로 (각 단계를 길게 한 줄, 짧게 한 줄 — 이미지 카드에 들어간다). 5개가 아니면 5개로 묶어 달라고 요청한다.
4. 글 하단 안내: 홈페이지 주소, 센터 소개 문구 3~5줄(자격·특징), 네이버 예약 링크, 도로명 주소, 네이버 톡톡 링크, 전화번호. 없는 항목은 "없음"
5. 네이버 장소: 글 아래에 넣을 지점 이름(네이버 지도에 등록된 이름 그대로) 1~3개
6. 배너: 글 맨 위에 넣을 배너 이미지 파일(없으면 "없음" → 배너 없이 진행), 배너 클릭 시 이동할 주소
7. 올릴 네이버 블로그 주소(계정은 내가 로그인)

[만들 것]
1. config/blog-center.json — 항목 이름은 docs/share/01 문서의 "설정 파일 항목" 표를 따른다.
2. 폴더: 블로그 초안/ (사진/, 사진_원본/, 사진_모자이크확인/ 포함). 위치는 바탕화면 아래, 다른 곳이면 알려 달라고 한다.
3. 전용 크롬 실행 파일(open-blog-editor.bat): 로그인 유지용 별도 프로필, 포트 9222. 만든 뒤 내가 로그인하도록 안내한다.
4. 점검: Claude Code 로그인 상태, 크롬 경로, ffmpeg, 파이썬(얼굴 모자이크용), 설정 파일 빈칸. 안 되는 것은 "무엇이 없고 어떻게 설치하는지"를 알려 준다.
5. 마지막에 시험: 논문 후보 검색 1회. 성공하면 "다음은 02 문서의 에디터 작성 프롬프트를 쓰면 된다"고 안내한다.

[끝내기 전 보고]
- 만든 파일 목록, 비어 있는 항목(나중에 채울 것), 내가 직접 해야 할 일(네이버 로그인, 승인 사진 준비)을 짧게 정리해서 알린다.
```

---

## 질문 예시 (AI가 이런 식으로 묻는다)

> 1단계로 센터 기본 정보부터 여쭤볼게요.
> ① 센터 이름 ② 센터 종류 ③ 지역(예: ○○시 ○○동) ④ 대표님 성함 ⑤ 호칭(기본: 대표)

## 설정이 끝났는지 확인하는 법
- `config/blog-center.json` 에 `[ ]` 대괄호가 남아 있으면 아직 빈칸이다 (프로그램이 실행 시 빈칸을 알려 주고 멈춘다).
- 센터 5단계는 반드시 5개여야 한다 (카드 이미지가 5칸 구조).
